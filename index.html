04. 课题实践与分析流程

Spatial & Single-Cell Project 2025 - Present

肺腺癌单细胞到空间转录组映射与侵袭前沿微环境生态位解析

整合原发与转移性肺腺癌的高通量单细胞与组织空间转录组数据，构建细胞空间解聚与原位坐标映射流水线。定量解析侵袭前沿（Invasive Front）恶性上皮细胞与基质、免疫细胞的空间共定位模式。

  • 建立严格的单细胞质控与批次校正规范，实现高保真原位空间映射。
  • 识别与局部微浸润显著相关的特征共表达模块及空间受配体通讯网络。
  • 基于 Python (Scanpy, Squidpy) 与 R 跨平台交叉验证分析结果。
scRNA-seq Spatial Visium Cell Deconvolution
Multi-Cohort Transcriptomics 2025 - Present

关键靶标及协同调控网络的多队列分子分型与临床预后建模

在 TCGA 及多个独立微阵列/RNA-seq 肺腺癌临床队列中，系统探究关键靶标及其协同调控轴的表达异质性、基因组变异关联与免疫微环境浸润特征。

  • 运用单/多变量 Cox 比例风险回归与机器学习筛选，验证候选特征跨队列预后稳健性。
  • 结合免疫浸润算法与基因集富集分析，阐明特征亚型的免疫微环境表型。
  • 输出符合高水平期刊标准的出版级统计图表与跨队列元分析报告。
TCGA / GEO Survival Analysis Machine Learning
