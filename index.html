from omics_agent import AuditWorkflow, DeconvolveNiche
 
adata_spatial = sq.read.visium("LUAD_Primary_vs_Metastasis")

# Execute cellular deconvolution & invasion boundary score
niche_res = DeconvolveNiche(adata_spatial, genes=target_genes)
AuditWorkflow.verify_reproducibility(niche_res, p_adj_thresh=0.01)

RESEARCH INTERESTS

核心研究方向与学术探索

Primary Research Area

肺腺癌（LUAD）单细胞与空间转录组生态位解析

利用 10x Genomics scRNA-seq 与 Visium 空间转录组 协同建模，探索肿瘤浸润边界（Invasive Front）的空间异质性。解决单细胞解聚（Deconvolution）到空间原位定位的映射难题，剖析恶性细胞克隆与成纤维细胞/巨噬细胞的空间通讯网络。

空间生态位 (Spatial Niche) 单细胞反褶积 (Cell Deconvolution) 侵袭转移轨迹
Target Discovery

SMAP2 轴与多组学分子分型

深入挖掘 SMAP2 及其协同分子群（CSRNP1, PDE4D, MMP1, HILPDA, COL6A5）在肿瘤转移过程中的功能定位，结合 TCGA 与 GEO 大样本队列构建高可信度的预后及分子亚型模型。

Methodology

Spatial Omics Project
Spatial Transcriptomics scRNA-seq Python & R

LUAD 单细胞到空间转录组映射与侵袭前沿生态位建模

针对肺腺癌原发灶与转移灶样本，构建单细胞参考数据集与 Visium 空间切片的联合分析管线。通过概率反褶积算法定位恶性细胞亚群与基质微环境在侵袭边界的共定位模式，解析促进局部微浸润的关键空间配体-受体对。

  • 实现了单细胞高维表型到组织切片空间坐标的原位高精度对齐
  • 挖掘并量化肿瘤侵袭前沿（Invasion Front）的特征细胞生态位与共表达模块
  • 严格遵循单细胞与空间质控标准，排除批次效应伪影
Multi-Omics Project
TCGA & GEO Survival Analysis Machine Learning

SMAP2 及协同基因家族的多队列分子分型与临床预后验证

在 TCGA-LUAD 及多个 GEO 独立队列（包括 GSE31210、GSE68465 等）中开展跨队列元分析。探究 SMAP2、CSRNP1、PDE4D、MMP1 等关键分子的表达异质性与免疫微环境浸润特征，构建稳健的分子亚型分层体系。

  • 跨越数百例临床样本的多中心验证，采用 Lasso-Cox 与多变量 Cox 比例风险回归
  • 结合 CIBERSORTx 与 ssGSEA 评估不同分子分型下的免疫抑制微环境特征
  • 产出符合顶级学术期刊标准的高质量出版级可视化图表（Heatmap, Volcano, Forest plots）
